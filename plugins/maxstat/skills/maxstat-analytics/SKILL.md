# MaxStat Analytics

Работайте с живым индексом MaxStat и возвращайте проверяемые ссылки, периоды,
даты наблюдения и стоимость запросов. Не переносите выводы на другие
мессенджеры и не обещайте доступ к закрытому контенту, которого нет у
авторизованного аккаунта.

## Рабочий порядок

1. Уточнить объект исследования, период, категорию, формат результата и
   допустимый расход кредитов.
2. При большом объёме сначала проверить тариф и остаток через
   `get_account_subscription` и `get_account_limits`.
3. Начинать исследование с `get_categories`, `search_channels` или
   `search_posts`, а не угадывать идентификаторы.
4. Разрешить стабильные идентификаторы каналов и публикаций через
   `get_channel` или `get_post`.
5. Запросить только необходимые истории показателей. Отличать текущее значение
   от дневной истории и всегда указывать период.
6. Для сравнения использовать одинаковые даты и метрики по всем объектам.
7. Вернуть факты отдельно от интерпретаций, приложить URL источников, дату
   наблюдения, оговорки и фактически использованные кредиты.

## Справочник инструментов

| Инструмент                    | Результат                                                  |                  Кредиты |
| ----------------------------- | ---------------------------------------------------------- | -----------------------: |
| `get_categories`              | Категории и текущее число каналов в каждой категории       |                Бесплатно |
| `search_channels`             | Поиск и фильтрация каналов с сортировкой и пагинацией      |                        3 |
| `get_channel`                 | Полная карточка канала по ID                               |                        1 |
| `add_channel`                 | Добавление публичного или invite-only канала в очередь     |                Бесплатно |
| `search_posts`                | Полнотекстовый поиск публикаций с фильтрами                |                        3 |
| `get_channel_subscribers`     | Дневная аудитория, минимум, максимум и рост                |                        5 |
| `get_channel_views`           | Суммарные, средние, максимальные и дневные просмотры       |                        5 |
| `get_channel_likes`           | Суммарные, средние, максимальные и дневные реакции         |                        5 |
| `get_channel_posts`           | Число публикаций, форматы и дневная активность             |                        5 |
| `get_post`                    | Контент, вложения, метрики, источник и пересылки           |                        1 |
| `get_post_views`              | Текущие и дневные просмотры публикации                     |                        5 |
| `get_post_likes`              | Реакции по типам и дневная история публикации              |                        5 |
| `create_channel_subscription` | Webhook на новые публикации канала                         | Бесплатно; 2 за доставку |
| `create_keyword_subscription` | Webhook на новые публикации по запросу                     | Бесплатно; 3 за доставку |
| `get_subscriptions`           | Список webhook-подписок и их статусов                      |                Бесплатно |
| `get_subscription`            | Одна подписка, статус доставки и последняя ошибка          |                Бесплатно |
| `update_subscription`         | Новый callback URL, пауза или возобновление                |                Бесплатно |
| `delete_subscription`         | Удаление webhook-подписки                                  |                Бесплатно |
| `get_account_subscription`    | Тариф, статус, период и состояние кредитов                 |                Бесплатно |
| `get_account_limits`          | Включённые, купленные, использованные и оставшиеся кредиты |                Бесплатно |
| `get_account_usage`           | Постраничная история списаний по запросам                  |                Бесплатно |

## Сценарии

### Найти подходящие каналы

1. Получить категории через `get_categories`.
2. Найти кандидатов через `search_channels`.
3. Проверить выбранные карточки через `get_channel`.
4. Вернуть название, URL, категорию, тип доступа, аудиторию и дату данных.

### Сравнить конкурентов

1. Разрешить ID каждого канала.
2. Для одного периода вызвать `get_channel_subscribers`,
   `get_channel_views`, `get_channel_likes` и `get_channel_posts`.
3. Сравнить абсолютный рост и темп роста, средние просмотры, средние реакции,
   частоту публикаций и распределение форматов.
4. Не объявлять лидера без явного критерия.

### Исследовать публикации

1. Найти публикации через `search_posts`.
2. Получить контент и вложения через `get_post`.
3. При необходимости запросить `get_post_views` и `get_post_likes`.
4. Вернуть URL, текст, тип, вложения, просмотры, реакции, даты и ограничения
   выборки.

### Проследить пересылки

Запросить `get_post` с данными об источнике и найденных пересылках. Отделить
оригинал от репостов, вернуть URL, даты и каналы назначения. Не считать
отсутствие найденных пересылок доказательством их полного отсутствия.

### Настроить мониторинг

1. Проверить, что callback — публичный HTTPS URL и принадлежит пользователю.
2. Для одного канала использовать `create_channel_subscription`.
3. Для ключевого слова и необязательной категории использовать
   `create_keyword_subscription`.
4. После создания проверить состояние через `get_subscription`.
5. Для диагностики использовать `get_subscriptions`, последнюю ошибку и
   состояние доставки.

### Контролировать использование

Перед пакетным исследованием вызвать `get_account_limits`. После него получить
`get_account_usage`, сопоставить списания с выполненными запросами и сообщить
остаток. Не запускать дорогую серию запросов, если лимита недостаточно.

## Безопасность

- Никогда не выводить, не сохранять и не передавать `MAXSTAT_API_TOKEN`.
- Не помещать токен в URL, логи, скриншоты, ответы или webhook payload.
- Не создавать webhook без подтверждённого публичного HTTPS callback.
- Не выполнять массовое добавление каналов или создание подписок без ясного
  запроса пользователя.
- Не утверждать, что индекс содержит весь приватный контент MAX.
- При ошибке авторизации предложить проверить переменную
  `MAXSTAT_API_TOKEN`, но не просить прислать её значение.

## Формат результата

Включить:

- задачу и критерии отбора;
- период анализа и дату наблюдения;
- таблицу сравнимых показателей;
- прямые URL каналов и публикаций;
- факты отдельно от выводов;
- ограничения индекса или выборки;
- количество вызовов и расход кредитов, если он существенен.

## Примеры запросов

- Найди 20 технологических каналов MAX с максимальным ростом за 30 дней.
- Сравни пять каналов по аудитории, просмотрам, реакциям и частоте публикаций.
- Найди публикации об ипотеке за июль и покажи вложения и пересылки.
- Настрой webhook на новые публикации по фразе «искусственный интеллект».
- Покажи мой тариф, остаток кредитов и десять последних списаний.
- Find the fastest-growing MAX channels in fintech over the last 30 days.
- Compare these MAX channels by reach, reactions, and publishing frequency.
- Find MAX posts about AI and list their detected forwards.
