# Публикация MaxStat MCP в каталогах

Актуально на 29 июля 2026 года.

<https://github.com/fbmdata/maxstat-mcp>, endpoint
`https://maxstat.ru/api/mcp` и название разработчика
**ООО «ФБМ Аналитикс» / FBM Analytics**.

## Нужна ручная проверка или изменение продукта

| Каталог  | Статус                                | Что требуется                                                                                                                                 |
| -------- | ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Smithery | Текущая схема авторизации не подходит | Для защищённого Streamable HTTP-сервера площадка требует OAuth, а MaxStat использует `X-API-Token`                                            |
| mcpub    | Ожидает production-деплой             | Discovery-card реализован и возвращает 200 на staging; `https://maxstat.ru/.well-known/mcp.json` остаётся 404 до запуска production-пайплайна |

## Площадки, которые сейчас не принимают MaxStat MCP

| Каталог              | Причина                                                                                                                                                |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| mcpdb.ru             | Форма падает из-за серверной ошибки конфигурации Auth.js                                                                                               |
| mcpserve.com         | Сайт возвращает `ERR_SSL_PROTOCOL_ERROR`                                                                                                               |
| MCP Archive          | Страница отправки ломается при React hydration                                                                                                         |
| MCP Find             | Принимает исходный код сервера вместе с пакетом npm, PyPI или Docker; в этом репозитории опубликован интеграционный пакет для размещённого MaxStat MCP |
| FindMCP.app          | Требует полностью открытый исходный код самого сервера                                                                                                 |
| MCP Curator          | Домен формы не разрешается через DNS                                                                                                                   |
| MCP Server Directory | Домен формы не разрешается через DNS                                                                                                                   |
| MCP Marketplace      | Площадка ориентирована на продажу пакетов и Stripe Connect; платное размещение не создавалось                                                          |

## Каноническое описание

### Короткое

Официальный MCP для аналитики MAX: поиск по 367K+ каналов и 85M+ публикаций,
аудитория, просмотры, реакции, репосты, динамика и webhooks.

### Полное

Официальный удалённый MCP-сервер MaxStat для аналитики мессенджера MAX. Даёт
AI-агентам 21 инструмент: поиск по 367K+ каналов и 85M+ публикаций, карточки
каналов и постов, динамику аудитории, просмотров, реакций и активности,
найденные репосты, webhook-мониторинг и контроль кредитов. Готовые интеграции
есть для Codex, Claude Code и Desktop, Cursor, VS Code, Windsurf, Gemini CLI,
GitHub Copilot CLI и других MCP-клиентов.
