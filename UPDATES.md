# Изменения MaxStat

Новости сервиса, публичного API и MCP. [Версии интеграции](CHANGELOG.md).

## Возможности на 8 ноября 2026

### Сервис

- **Мониторинг:** отслеживайте новые публикации канала, его упоминания и репосты,
  а также ключевые фразы в публикациях и комментариях.
- **Уведомления:** получайте события в личных чатах, группах и каналах MAX
  и Telegram или на Webhook. Добавьте получателей в разделе
  [«Уведомления»](https://maxstat.ru/dashboard/notifications), затем выберите их
  в [мониторинге](https://maxstat.ru/dashboard/monitoring).
- **История:** события хранятся 90 дней. Сбор начинается после включения
  отслеживания. Старые публикации в историю не добавляются.

Для активного мониторинга нужен платный тариф. Одно место входит в тариф;
дополнительные можно купить в кабинете. Одно отслеживание — один канал
или запрос до 50 фраз с фильтром до 100 каналов. Приостановленные отслеживания
место не занимают.

На одно отслеживание действует лимит 1 000 событий в сутки по Москве.
Для доставки в мессенджеры — до 10 сообщений в минуту и 100 событий мониторинга
в сутки на получателя. История сохраняется и без Webhook. После подключения
получателя проверьте доставку в нужный чат, группу или канал.

[Описание мониторинга](https://maxstat.ru/promo/monitoring) ·
[Настройка и ограничения](README.md#мониторинг-в-личном-кабинете).

### Публичный API и MCP

- Публичный API содержит 15 операций для каналов, публикаций, аналитики,
  тарифа и расхода кредитов. Они же доступны как инструменты MCP.
- Мониторинг и получатели уведомлений настраиваются в кабинете.
  В публичном API и MCP операций для управления ими нет.
- Старые MCP-инструменты webhook-подписок удалены. При `Unknown tool` обновите
  список инструментов и уберите старые вызовы. `get_account_subscription`
  по-прежнему показывает тариф.

[Документация API](https://maxstat.ru/api/docs) ·
[OpenAPI-схема](https://maxstat.ru/api/openapi.json) ·
[Инструменты и стоимость вызовов](README.md#инструменты-mcp).
После подключения проверьте список MCP-инструментов через `tools/list`.
